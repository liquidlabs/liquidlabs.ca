🤖 CodeMateX — On-Device AI Coding Tutor & Learning Lab 🚀

CodeMateX is your intelligent, on-device AI coding companion and interactive learning lab. Built for mobile engineers, students, and software developers, CodeMateX runs optimized Large Language Models (LLMs) locally on your device hardware using Google's cutting-edge LiteRT runtime. Prompts, learning queries, and AI chats run 100% locally on-device without cloud LLM subscriptions or privacy compromises.

Key Features

📚 Interactive Guided Courses & Syllabi

10+ bundled offline-first courses: Kotlin Tour (Beginner & Intermediate) + Foundations, Go by Example (85+ lessons) + Foundations, Rust by Example (196+ lessons) + Foundations, Python, TypeScript, and Swift (600+ total lessons). Easily explore curriculum with sticky language filter chips.

▶️ In-App Code Execution & Terminal Runner

Run interactive code snippets in Kotlin, Go, Rust, Python, and TypeScript with live terminal console output. Uses secure cloud sandbox proxy execution when connected, and automatically switches to offline reading mode when disconnected so study is never interrupted.

✅ Interactive Quick-Check Quizzes

Real-time conceptual multiple-choice quizzes with instant visual validation and explanations to test and reinforce your knowledge.

🧠 100% Local On-Device AI

Powered by Google LiteRT-LM (supporting Gemma 2 2B, Qwen 2.5 Coder, Qwen 3, Phi-4 Mini). AI inference runs 100% on your device hardware with zero cloud LLM API calls, zero subscription fees, and complete offline capability.

🛡️ Complete Chat Privacy & Security

Your code prompts, questions, and conversation history never leave your device. No user accounts, advertising trackers, or cloud telemetry data collection required.

🎨 Code Block Customization & AI Personas

Syntax highlighting powered by our open-source Compose Highlight library for Jetpack Compose. Includes Highlight.js syntax themes (Tomorrow Light/Night, Atom One, GitHub, Dracula), configurable density, and line numbers. Choose tunable AI tutor personas (Senior Architect, Beginner Tutor, Interview Coach) tailored to your learning pace.

💻 Specialized Developer Tutoring Topics

Get targeted guidance with interactive topic tracks tailored for modern development: Kotlin idioms, Android Jetpack & Modern Architecture (MVI/MVVM), Jetpack Compose & Material 3, Coroutines & Flow, Bug Triaging, System Design, Algorithms, Python, Swift, and Rust.

📊 Real-Time Technical Benchmarking Dashboard

Inspect hardware execution metrics in real time: Hardware Backend acceleration badges (NPU, GPU OpenCL/Vulkan, and CPU), Time-to-First-Token (TTFT) prefill latency, active decode throughput (tokens/sec), and memory footprint boundaries.

📱 Modern Material 3 Expressive Design

Built entirely with Jetpack Compose following Material 3 Expressive guidelines. Features atmospheric ambient lighting, dynamic topic visual branding, and adaptive layouts tailored for compact phones, foldables, and tablets.

Hardware Requirements & Optimization

To deliver responsive on-device LLM inference without taxing the operating system, CodeMateX is optimized for modern high-performance Android devices:

  • 💾 RAM: 8 GB RAM minimum recommended for smooth LLM model execution.
  • ⚡ Processor: 64-bit architecture (ARM64-v8a).
  • 🎮 Graphics Acceleration: Vulkan 1.1+ compute shaders or OpenCL GPU acceleration.
  • 🔋 Efficiency: Fully local inference with zero background battery drain when idle.
  • 🧩 Syntax Highlighting: Powered by the open-source Compose Highlight library for Jetpack Compose.
