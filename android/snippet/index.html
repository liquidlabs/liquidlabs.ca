Snippet — Code Notebook & AI

Your personal code notebook, AI companion, and Gists sync tool for Android

⚡ Beautiful Code Notebook. Intelligent Assistant. 100% Private.

Snippet is your personal code notebook and developer companion for Android. Designed specifically for programmers, engineers, and computer science students, Snippet lets you capture, organize, search, generate, and share beautiful syntax-highlighted code wherever you go.

Whether you are saving quick code snippets from StackOverflow, brainstorming architecture with an AI code assistant, syncing your GitHub Gists, or exporting polished code cards for social media, Snippet keeps your developer workflow fast, focused, and completely private.

Key Features

🎨 Desktop-Grade Syntax Highlighting

Powered by compose-highlight, enjoy buttery-smooth syntax highlighting right on mobile. Choose from dozens of professional themes (Dracula, Monokai, GitHub Dark/Light, Nord, Solarized, Material Ocean) optimized for readability in Dark and Light modes.

📁 Unified Code Notebook & Instant Search

A chronological feed keeps all your snippets and clipboard clips organized in one place. Powered by SQLite FTS4 full-text search, instantly search functions, variables, comments, or tags in milliseconds. Ingest code from any app via Android's native share sheet.

🤖 AI Code Assistant (BYOK)

Multi-turn AI chat to debug compiler errors, explain complex logic, or explore unfamiliar syntax. Bring Your Own Key (BYOK) with Cloudflare Workers AI, OpenRouter, or OpenAI-compatible endpoints. Tap curated prompt badges for Kotlin, TypeScript, Python, Rust, Go, SQL, or Swift, and save generated snippets directly to your notebook with 1 tap.

🐙 GitHub Gists Two-Way Sync

Connect your GitHub account securely via Personal Access Token (PAT). Browse and read multi-file Gists with markdown and syntax rendering, turn local snippets into public or secret Gists, and sync cloud gists locally with full offline backup.

📸 Styled Code Card Export

Generate high-resolution Carbon- and Ray.so-style code card images directly from your device. Customize radiant gradients, window controls (macOS traffic lights), language monograms, and syntax themes to share clean code on Slack, Discord, Reddit, or social media.

🛡️ 100% Private & Offline-First

Zero analytics trackers, zero advertising SDKs, and zero telemetry. All snippets, tags, and search indexes are stored locally on your device in a secure SQLite database. API keys and GitHub tokens are encrypted with Android Encrypted DataStore.

Architecture & Open Source

Snippet is an open-source reference application engineered with modern Android development best practices:

  • 🎨 Jetpack Compose & Material 3 Expressive: Fully declarative UI with dynamic colors and adaptive layouts for phones, foldables, and tablets.
  • ⚡ compose-highlight: Open-source syntax highlighting library developed by Liquid Labs Inc.
  • 🏛️ Slack Circuit UDF: Unidirectional data flow architecture with clear separation of UI and Presenter logic.
  • 🔍 SQLite FTS4: Fast, local, full-text search indexing on device.
  • 🔐 Encrypted DataStore: Hardware-backed encryption for user API keys and GitHub tokens.
  • 🚀 Baseline Profiles: Ahead-of-time compilation profiles for blazing-fast app startup and fluid scrolling.
